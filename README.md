# دليل معادلة الشهادات في سورية

تطبيق عربي عام ومبسّط لشرح خطوات معادلة الشهادات الجامعية والأجنبية في سورية.

**إعداد المهندس خالد الأسعد**  
**هذا التطبيق تابع للمهندس خالد الأسعد**

## ماذا يحتوي التطبيق؟

- مسار خاص للشهادات الصادرة من النرويج.
- خطوات تجهيز الملف داخل سورية.
- قائمة تحقق للأوراق المطلوبة.
- حالات خاصة: لبنان، أكثر من جامعة، ثانوية غير سورية، طالب موفد، طالب موظف، هندسة مدنية، اختصاصات طبية.
- زر تواصل مباشر عبر واتساب.
- تصميم عربي RTL مناسب للهاتف والنشر على Vercel.

## تعديل المحتوى لاحقًا

كل المحتوى الأساسي موجود في:

```text
/data/guide.ts
```

لتحديث أي معلومة مستقبلًا، عدّل هذا الملف فقط، ثم ادفع التحديث إلى GitHub وسيُعاد نشر الموقع تلقائيًا عبر Vercel عند الربط.

## التشغيل المحلي

```bash
npm install
npm run dev
```

ثم افتح:

```text
http://localhost:3000
```

## النشر على Vercel

1. افتح Vercel.
2. اختر **Add New Project**.
3. اختر هذا المستودع من GitHub.
4. اترك الإعدادات الافتراضية لـ Next.js.
5. اضغط **Deploy**.

لا يحتاج المشروع إلى متغيرات بيئة في النسخة الأولى.

## تنبيه

المعلومات داخل التطبيق إرشادية وقد تتغير. يجب دائمًا مراجعة وزارة التعليم العالي والجهات الرسمية قبل تقديم أي معاملة.
